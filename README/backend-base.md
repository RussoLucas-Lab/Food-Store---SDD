### 6. Testing de la estructura backend

- Para correr los tests iniciales, ubicarse en la raíz del proyecto y ejecutar:

```bash
pytest tests/
```
(o bien `python -m pytest tests/` si pytest está instalado)

- El archivo `tests/test_placeholder.py` es solo una plantilla para que pase un test básico. Debe reemplazarse cuando haya lógica implementada.
